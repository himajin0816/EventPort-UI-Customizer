拡張機能名: EventPort UI Customizer
最終更新日: 2026年9月24日

本拡張機能（EventPort UI Customizer、以下「当拡張機能」）は、ユーザーのプライバシーを尊重し、個人情報の保護に最大限の配慮を行っております。本ポリシーでは、当拡張機能における利用者の情報の取扱いについて説明します。

1. 収集する情報とその利用目的

当拡張機能は、ユーザーの個人情報（氏名、メールアドレス、パスワード、アカウント情報、決済情報、サークル参加申込内容等）を収集・取得・外部送信することは一切ありません。

1-1. 拡張機能の設定データ（ローカル保存）

  • 対象: 過去イベント非表示のON/OFF、初期並び順設定、締切警告の有効/無効、同日他イベントのグレーアウト設定
  • 保存先: お使いのブラウザ内部のローカルストレージ（chrome.storage.local）
  • 利用目的: ユーザーが設定した表示設定を保持し、次回ページ表示時に適用するためのみに使用されます。このデータが外部サーバーへ送信されることはありません。

1-2. 外部通信について（ボイベまとめ API / ICS）

  • 当拡張機能は、イベントの募集締切日や申込変更締切日を警告表示する機能を提供するため、音声合成系イベント開催情報まとめサイト「ボイベまとめ（https://vo.nrsy.jp/）」の管理者様より正式にデータ利用の許諾をいただいた上で、公開イベント情報フィードと通信を行います。
  • この通信は公開カレンダーデータを受信するためだけの読み取り専用通信であり、ユーザーを特定できる識別子や閲覧履歴、入力情報などを送信することは一切ありません。
  • また、外部サーバーへの通信負荷を最小限に抑えるため、取得したデータはブラウザ内に24時間一時キャッシュされます。

2. 権限（Permissions）の利用目的

  • storage: ユーザーの表示設定をブラウザローカルに保存・読み込みするため。
  • https://event-port.com/*: EventPort の対象4ページ（/dashboard, /circle-participation, /seller-participation, /general-participation）において、一覧表のソート、過去イベントの非表示、申込状況の強調表示を行うため。
  • https://vo.nrsy.jp/*: ボイベまとめ管理者様よりデータ利用許諾を得た上で、公開カレンダーデータから締切日情報を取得し、締切警告を表示するため。

3. 第三者へのデータ提供

当拡張機能は、ユーザーのいかなるデータも収集・保管していないため、第三者への提供、販売、共有を行うことは一切ありません。

4. プライバシーポリシーの変更

当拡張機能の機能追加や規約改定に伴い、本プライバシーポリシーを改定することがあります。重要な変更がある場合は、拡張機能の更新情報等を通じてお知らせします。

5. お問い合わせ

本プライバシーポリシーまたは当拡張機能に関するお問い合わせは、配布ページ（Chrome ウェブストアのサポートタブまたは GitHub リポジトリの Issue）よりお願いいたします。
